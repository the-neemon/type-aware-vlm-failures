\column{0.62\textwidth}
\small
\begin{tabular}{L{0.42\linewidth}L{0.46\linewidth}}
\toprule
\textbf{Misread (structural)} & \textbf{Fabrication} \\
\midrule
``Value of Mango?'' $\to$ \alert{30} (true 34) & ``Value of Guava?'' $\to$ \alert{40} (no Guava bar) \\
The answer is on the chart; the model read it badly &
The model states something the chart does not contain \\

\bottomrule
\end{tabular}
\vspace{0.6em}

Existing failure detectors give one ``wrong / right'' score, so they cannot
choose between these two fixes.
\end{columns}

\begin{frame}{Research question and hypothesis}
\textbf{Question.} Before a VLM answers a chart question, can its hidden state tell
us (1) whether the answer will be wrong, and (2) which type of error it will be?
And does the type decide which repair works?
\vspace{0.8em}

\textbf{Type Separability Hypothesis.} The hidden state before a misread is
linearly distinguishable from the hidden state before a fabrication: a misread is
a precision-limited perception error, a fabrication is an answer not grounded in
the image.
\vspace{0.8em}

If the two collapse into one signal, that is a reportable outcome too.
\end{frame}

\begin{frame}{Setup}
\begin{columns}[T]
\column{0.5\textwidth}
\footnotesize
\textbf{Models} (frozen, fp16, greedy, max 32 tokens)
\begin{itemize}
\item Qwen2.5-VL-7B (28 layers, $d=3584$)
\item LLaVA-NeXT-7B, Mistral LM (32 layers, $d=4096$)
\end{itemize}
\textbf{Data}
\begin{itemize}
\item ChartQA test: 2,500 questions (1,250 human, 1,250 machine-generated)
\item ChartQA validation: 960 human questions (Qwen)
\item Three synthetic pilots: 900 bar charts
\end{itemize}
\column{0.5\textwidth}
\footnotesize
\textbf{Activations}
\begin{itemize}
\item Forward hooks inside the \emph{same} \texttt{generate()} call that produced
the scored answer
\item Every layer, 4 pooled positions: image-token mean and max, last prompt
token, prompt mean
\end{itemize}
\textbf{Probes}
\begin{itemize}
\item $L_2$ logistic regression on one vector, scored by AUROC
\item Splits by \emph{chart}, never by question; layer and $L_2$ chosen without
the test set
\item 95\% CIs from a bootstrap over charts
\item Always next to a baseline that sees no activations
\end{itemize}
\end{columns}
\end{frame}

\begin{frame}{E1: how the numbers are computed}
\begin{columns}[T]
\column{0.5\textwidth}
\small
\textbf{AUROC}
\begin{itemize}
\item Charts split 60/20/20 into train / validation / test
\item Layer (1 of 28 or 32), position and $L_2$ chosen on validation
\item Test set scored \textbf{once} with that choice; CI from 2,000 bootstrap
resamples of test charts
\end{itemize}
\textbf{Surface features} (4 numbers per question)
\begin{itemize}
\item question written by a human or generated
\item question length in characters
\item number of image tokens (image size)
\item whether the gold answer is a number
\end{itemize}
\column{0.5\textwidth}
\small
\textbf{Removing them}: regress each hidden-state dimension on the 4 features
(fitted on training charts only), subtract the fit, retrain the probe on what is
left
\vspace{0.3em}

\textbf{Is it more than surface features?} Yes, for both models:
\vspace{0.2em}

\centering
{\footnotesize\setlength{\tabcolsep}{4pt}
\begin{tabular}{lccc}
\toprule

\midrule
Qwen & 0.88 & 0.80 & 0.72 \\
LLaVA & 0.80 & 0.78 & 0.61 \\
\bottomrule
\end{tabular}}
\vspace{0.3em}

\raggedright
With the features removed, the probe stays close to the full probe and well
above the features alone: it learns an internal property of the model's state,
beyond what the question's surface reveals.
\end{columns}
\end{frame}

\begin{frame}{E3 (ChartQA): question-type control}
\footnotesize
\textbf{Concern.} Arithmetic errors only happen on questions that ask for a
calculation (``What is the \emph{difference}\dots'', ``\dots the \emph{average}''),
while misreads happen on ``What is the value of\dots'' questions. A probe could
separate the two just by recognising the question wording.
\vspace{0.3em}

\textbf{Control.} Tag every question as \emph{arithmetic} (difference, sum,
average, ratio, \dots) or \emph{reading} (all others), then compare errors with
correct answers \textbf{to the same kind of question}, where the wording no
longer differs:
\begin{center}
\begin{tabular}{lcc}
\toprule
 & Qwen & LLaVA \\
\midrule
Arithmetic error vs.\ correct, arithmetic questions only & 0.85 & 0.84 \\
Misread vs.\ correct, reading questions only & 0.91 & 0.81 \\
\bottomrule
\end{tabular}
\end{center}
The probe still works, so it detects the error, not only the question type.
\vspace{0.3em}

\textbf{Why we need synthetic charts.} The project's main comparison is
\emph{misread vs.\ fabrication}, but ChartQA has only 1 (Qwen) and 17 (LLaVA)
fabrications, too few to train a probe. So we built charts where fabrication can
be induced.
\end{frame}

\section{Part 3: fixes by error type}

\begin{frame}{E4: four repairs}
\begin{columns}[c]
\column{0.5\textwidth}
\small
Every wrong answer on the synthetic value questions is asked again (Qwen 631,
LLaVA 1,015 errors):
\begin{itemize}
\item \textbf{Re-ask}: same question again, sampled (temperature 0.7); controls for
``a second try''
\item \textbf{Upsample}: the whole chart, enlarged
\item \textbf{Crop}: only the asked bar and the y-axis, enlarged
\item \textbf{Verify}: ``First name the part of the chart that supports your
answer, then answer''
\end{itemize}
\textbf{Pre-registered prediction} (written before running): crop rescues misreads
more than fabrications, because for a fabrication there is nothing to look at.
\column{0.48\textwidth}
\centering
\includegraphics[height=3.6cm]{figures/synth_pilot2.png}\hspace{0.4em}
\includegraphics[height=3.6cm]{figures/synth_crop_example.png}\\
\scriptsize Original chart, and the crop for ``What is the value of Slovenia?''
\end{columns}
\end{frame}

\begin{frame}{E4: how crop and upsample work}
\begin{columns}[T]
\column{0.5\textwidth}
\footnotesize
\textbf{Which part is cropped?}
\begin{itemize}
\item The chart generator records the pixel box of every bar and of the plot area
\item The question names a category (``Slovenia''); we find its bar by name
\item Keep the y-axis strip (tick labels) and the bar $\pm$12 pixels, full height
(so the bar's label and the top of the scale stay), joined side by side
\item If the named bar is not on the chart (fabrication case), there is nothing
to crop and the whole chart is shown
\end{itemize}
\column{0.48\textwidth}
\footnotesize
\textbf{Does enlarging overload the model?}
\begin{itemize}
\item Both repairs are enlarged to the \textbf{same pixel budget}: 1,000,000 pixels
(the cap of the original run), at most 4$\times$
\item Qwen makes one image token per 28$\times$28 pixels, so the budget caps it at
about 1,275 tokens; crop and upsample get the same number
\item LLaVA-NeXT resizes every image to its own fixed tile layout, so enlarging
adds no tokens there either
\item Crop vs.\ upsample therefore isolates \emph{where} the pixels go, not
\emph{how many}. Example: crop 211$\times$720 $\to$ 541$\times$1847; full chart
960$\times$720 $\to$ 1154$\times$866
\end{itemize}
\end{columns}
\end{frame}

\centering
\footnotesize

\raggedright
\begin{itemize}\footnotesize
\item \textbf{Pre-registered test passes} in both models: crop helps misreads more

\item Qwen's best repair differs by type: crop for misreads, verify for missing
bars (it makes Qwen say ``not shown'')
\item Nothing fixes LLaVA's missing-bar answers; for those, only abstaining helps
\end{itemize}
\end{frame}

\begin{frame}{E5: type-aware controller}
\small
\textbf{Selective prediction}: a system may abstain. Each policy ranks the 1,200
synthetic value questions by confidence and abstains on the least confident first.
\vspace{0.4em}
\begin{itemize}
\item \textbf{Plain model}: answers everything
\item \textbf{Binary abstention}: abstain when the wrong-vs-right probe fires
\item \textbf{Controller}: re-look with the best E4 repair when the misread probe
fires; abstain when the missing-bar probe fires
\item \textbf{Re-look + binary}: the controller's re-look, then binary abstention
\item \textbf{Oracle}: knows the true error type (upper bound)
\end{itemize}
Thresholds and the repair are chosen on four chart folds and applied to the fifth.
A re-look that breaks a right answer counts against the policy (crop breaks 133 of
Qwen's 554 right answers).
\end{frame}

\begin{frame}{E5: risk-coverage curves}
\begin{columns}[c]
\column{0.6\textwidth}
\includegraphics[width=\textwidth]{figures/slide_risk_coverage.pdf}
\column{0.38\textwidth}
\scriptsize
\textbf{How to read it.} Move right to left: the policy abstains on more

\begin{itemize}
\item x: coverage, the fraction answered
\item y: risk, the error rate among answered
\item Lower is better; the right end (coverage 1) is answering everything

\item Re-looking lowers the right end (Qwen 0.53 $\to$ 0.34): fixed answers
\end{itemize}

\begin{frame}{E5: findings}
\begin{itemize}
\item Re-looking lowers error in both models, under either abstention ranking
\item The controller beats binary abstention only for Qwen, mostly by turning
``0'' answers into ``not shown'' (212 of its 222 fixes)
\item For LLaVA, missing-bar abstention ranks worse than the binary probe, and
re-looking fixes only 12 misreads
\item Best probe policy: re-look, then rank by the binary probe
\item The oracle is far better (0.06 and 0.50): better policies are possible
\end{itemize}
\end{frame}

% ===========================================================================
\section{Conclusions}

\begin{frame}{Conclusions}
\begin{enumerate}
\item The hidden state predicts that an answer will be wrong \textbf{before} it is
written, beyond what surface features explain (0.88 Qwen, 0.80 LLaVA)
\item On real charts the errors are misreads and arithmetic errors, and the two
are separable (0.90, 0.96), also within one question type
\item Models \textbf{know} when a chart cannot answer the question (0.96 to 1.00),
for missing names and out-of-range years, and answer anyway
\item The error type changes the best repair: crop rescues misreads, not
fabrications, as pre-registered
\end{enumerate}
\end{frame}

\begin{frame}{Limitations}
\begin{itemize}
\item Fabrication is rare on real charts, so misread vs.\ fabrication rests on
synthetic bar charts
\item Synthetic misreads largely reflect gridline geometry
\item Labels come from an LLM annotator; two humans agreed with each other only
at $\kappa=0.42$
\item Repairs and the controller are tested on synthetic charts only
\item Probes show what is encoded, not that the model uses it
\end{itemize}
\end{frame}
